	public function create(Ingrediente $ingrediente) {

		$con = Conexion::getConection();

		$nombre 	= $ingrediente->getNombre();
		$foto 		= $ingrediente->getFoto();
		$precio 	= $ingrediente->getPrecio();
		$alergenos 	= $ingrediente->getAlergenos();


		$stm = $con->prepare(
			"INSERT INTO ingrediente (nombre, foto, precio) VALUES (:nombre, :foto, :precio)"
		);

			'foto' 			=> $foto,
			'precio' 		=> $precio,
		]);

		$ingrediente_id = $con->lastInsertId();

		$this->assoc_alergenos($ingrediente_id, $alergenos);

	public function assoc_alergenos($ingrediente_id, $alergenos) {
		$con = Conexion::getConection();

		// Verificar que $alergenos sea un array y no esté vacío
		if (!is_array($alergenos) || empty($alergenos)) {
			echo "No hay alérgenos para asociar al ingrediente.";
			return;
		}

		foreach ($alergenos as $alergeno) {
			// Asegúrate de que cada $alergeno sea una instancia de Alergeno

				$stm = $con->prepare(
					"INSERT INTO ingrediente_has_alergeno (Ingrediente_id, Alergeno_id) VALUES (:ingrediente_id, :alergeno_id)"
				);

					'ingrediente_id' => $ingrediente_id,
					'alergeno_id' => $alergeno->getId(),
				]);
			} else {
				echo "El alérgeno no es válido.";
			}
		}
	}

		$objets = [];

		$objets = [];

				$response['foto'],

		while ($response = $stm->fetch(PDO::FETCH_ASSOC)) {
			$ingrediente_id = $response['Ingrediente_id'];

	public function assoc_alergenos($ingrediente_id, $alergenos) {
		$con = Conexion::getConection();

		// Verificar que $alergenos sea un array y no esté vacío
		if (!is_array($alergenos) || empty($alergenos)) {
			echo "No hay alérgenos para asociar al ingrediente.";
			return;
		}

		foreach ($alergenos as $alergeno) {
			// Asegúrate de que cada $alergeno sea una instancia de Alergeno
			if ($alergeno instanceof Alergeno) {
				$stm = $con->prepare(
					"INSERT INTO ingrediente_has_alergeno (Ingrediente_id, Alergeno_id) VALUES (:ingrediente_id, :alergeno_id)"
				);

				$stm->execute([
					'ingrediente_id' => $ingrediente_id,
					'alergeno_id' => $alergeno->getId(),
				]);
			} else {
				echo "El alérgeno no es válido.";
			}
		}
	}

	public function getByIds($ids) {

		$con = Conexion::getConection();

		// Preparar la consulta para buscar por el email
		$stm = $con->prepare("SELECT * FROM ingrediente WHERE id in (:id)");
		$stm->execute(['id' => implode(',', $ids)]);

		$objets = [];

		// Obtener el resultado como un array asociativo
		while ($response = $stm->fetch(PDO::FETCH_ASSOC)) {

	protected function __mm__alergenos($ids) {
		if (empty($ids)) {
			return [];
		}

		$con = Conexion::getConection();

		// Crear los placeholders
		$placeholders = implode(',', array_fill(0, count($ids), '?'));
		$stm = $con->prepare("SELECT Ingrediente_id, Alergeno_id FROM ingrediente_has_alergeno WHERE Ingrediente_id IN ($placeholders)");

		// Ejecutar la consulta con los IDs de los ingredientes
		$stm->execute($ids);

		$objets = []; // Relacionará ingrediente_id con alérgeno_ids
		$alergenos_tmp = [];

		while ($response = $stm->fetch(PDO::FETCH_ASSOC)) {
			$ingrediente_id = $response['Ingrediente_id'];
			$alergeno_id = $response['Alergeno_id'];

			// Asociar los alérgenos con el ingrediente
			$objets[$ingrediente_id][] = $alergeno_id;

			// Guardar los IDs de los alérgenos únicos
			$alergenos_tmp[$alergeno_id] = $alergeno_id;

		// Obtener los objetos completos de los alérgenos por sus IDs

			return [];

La lógica del método insertIngredients debería ser la siguiente:

El cliente envía los datos de un nuevo ingrediente y sus alérgenos.
El método insertIngredients crea un nuevo objeto Ingrediente con esos datos y usa el repositorio RepoIngrediente para insertarlo en la base de datos.
Si hay alérgenos, se asociarán con el ingrediente mediante el método assoc_alergenos.
Flujo de Inserción:

Crear el Ingrediente:

El cliente envía los datos del ingrediente (nombre, foto, precio, etc.).
El RepoIngrediente crea un nuevo objeto Ingrediente.
Guardar el Ingrediente:

Usamos el método create() del RepoIngrediente para insertar el ingrediente en la base de datos.
Asociar los Alérgenos:

Si el cliente envía alérgenos, el método assoc_alergenos() se encargará de asociar esos alérgenos con el ingrediente recién insertado.
Respuesta:

Si todo va bien, el servidor responderá con un mensaje de éxito y los detalles del ingrediente insertado.

public function insertIngredients($data) {
    $repoIngrediente = new RepoIngrediente();
    $repoAlergeno = new RepoAlergeno();

    $ingrediente = new Ingrediente(

Flujo detallado:

El cliente envía una solicitud POST con los datos del ingrediente y sus alérgenos.
El método insertIngredients crea un nuevo objeto Ingrediente.
El repositorio RepoIngrediente lo guarda en la base de datos y asocia los alérgenos con assoc_alergenos().
El servidor responde con el ingrediente recién creado.
Resumen:
ApiIngrediente: Actúa como el controlador que recibe las solicitudes HTTP, decide qué hacer y envía respuestas JSON al cliente.
RepoIngrediente: Interactúa con la base de datos, realizando las operaciones de CRUD (crear, leer, actualizar, eliminar) en la tabla de ingredientes y la tabla intermedia de relación entre ingredientes y alérgenos.
Flujo: El cliente hace una solicitud (ej. GET o POST), la API procesa la solicitud usando los repositorios, y luego devuelve los datos en formato JSON.
Este flujo permite que la API sea extensible y modular, separando la lógica de negocios (en los repositorios) de la lógica de presentación (en la API).
